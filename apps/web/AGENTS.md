# apps/web: the Parry site and app

Next.js 16 App Router, React 19, Tailwind 4, TypeScript strict.
This Next version differs from older training data: read `node_modules/next/dist/docs/` before changing routing, metadata, caching or config.
`cacheComponents` is on, so routes kept in the background stay mounted (hidden); reset transient UI in `useLayoutEffect` cleanups.

## Commands

```bash
pnpm --filter @parry/web dev         # local dev server
pnpm --filter @parry/web lint        # ESLint, zero warnings allowed
pnpm --filter @parry/web typecheck   # next typegen, then tsc
pnpm --filter @parry/web test        # vitest unit tests (lib, components)
pnpm --filter @parry/web e2e         # builds, starts, runs Playwright (Chromium 1.64)
SCREENS=1 pnpm --filter @parry/web e2e screens   # full page screenshots to test-results/screens
pnpm --filter @parry/web icons       # regenerate every brand asset from scripts/brand.mjs
```

## Layout

- `app/(site)`: landing and legal pages; `app/app`: the app shell and its routes; `app/tokens.css` mirrors `packages/brand/tokens.json` (a unit test keeps them equal).
- `components/ui`: the design system; `components/site`: landing; `components/app`: shell, nav, `ConnectButton`.
- `lib/`: env, CSP, theme, stats fetch, risk tiers, explorer links, the hero geometry (`deflection.ts`).

## Conventions and traps

- Theme: `<html data-theme>` set before paint by the inline script in `app/layout.tsx`; the choice lives in localStorage `parry-theme`.
- Tailwind has no default palette (`--color-*: initial`); use the token utilities (`bg-surface`, `text-muted`, `text-brass`, tier colors).
- Motion: framer-motion only through `m.*` under the root `LazyMotion`; GSAP and Lenis only on the landing page, loaded after hydration; everything honors reduced motion.
- Never show a figure that did not come from the API; the live strip shows "unavailable" instead.
- `components/brand/paths.ts` and the icons are generated by `scripts/brand.mjs`; edit the script, not the outputs.
- Scrub traps: no em dash, and no class or SVG attribute containing the scrubbed word for vertical text alignment (use `items-end`, offsets).
